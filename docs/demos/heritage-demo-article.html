About this multilingual demo

This site is a Joomla Playground running entirely in your browser. A blueprint set it up as a multilingual site in five languages: English, Dutch, German, French and Spanish. Its content, about UNESCO World Heritage sites, comes from the demonstration data plugin and module by Clifford E Ford.

What makes a Joomla site multilingual

  1. Language packs. Each language has a language pack, with the translations of Joomla's own texts for the site and the administrator (System > Install > Languages).
  2. Content languages. A content language (Content > Content Languages) tells Joomla which languages the content is in. It also gives each language its code in the URL, such as /nl/.
  3. The Language Filter plugin. The System - Language Filter plugin reads the language from the URL. If the URL has none, it takes the language from the browser or the site default. It shows only the content in that language, or in All languages, like this article.
  4. A Home page for every language. Each content language has its own menu with a Home menu item in that language. The default Home item is set to All languages.
  5. Content per language. Articles, categories, menu items and modules each have a language. Associations link the translations of an item, so the language switcher can go to the same page in another language (Components > Multilingual Associations).
  6. The Language Switcher module. It shows the content languages, here as flags at the top of the page.

Try it

  • Switch languages with the flags, and see how the menus, the modules and the articles change.
  • In the administrator, System > Multilingual Status checks the setup.
  • Content > Articles can be filtered by language. The Multilingual Associations component shows the translations side by side.

How this site was made

A blueprint is a list of steps for a new playground. This one installs the language packs and publishes their content languages, enables the Language Filter, adds a Language Switcher, installs the demonstration data extensions, chooses the heritage dataset in five languages, installs it, and adds this article. The blueprint is blueprints/heritage-demo.json in the Joomla Playground repository.
